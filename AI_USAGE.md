AI Usage Documentation 
1. Tools used

I used ChatGPT during the creation of this project.

2. Key prompts 

-Help me build the Companies CRUD process step by step using Flask and MySQL.
Which helped me figure out where to start and a good base framework to use for the other processes.

-Help me set up the companies html that uses all these crud functions. 
This also similarly helped me make the other html options for all the other processes that I made.

-Help me create a Job Match feature that compares user skills with job requirements.
This helped me make the job match feature and helped me add the Json functionality to the jobs and applications html.

-Help me improve the size and appearance of my HTML tables using CSS
I asked for this after my applications table grew too big for the screen.

3. What Worked Well 

-ai built the companies crud quickly and made it easy to understand and adjust to make it function with the other process.

-every time I got a minor error it told me a quick fix or if some issue came up it gave me several options to improve my code.

4. What I Modified

-I modified AI-generated code to match my actual database schema, table names, and column names.

-Tested Flask routes and SQL queries and corrected issues when they appeared.

-Customized the HTML forms and tables to fit the information stored in my database.

5. Lessons Learned

-Testing code is important because AI-generated suggestions may need adjustments.

-Breaking a large programming project into smaller steps makes it easier to understand, develop, and debug.

-AI is a useful development assistant, but it is important to understand, review, and test the code rather than simply copying it.

6. Conclusion

-ChatGPT was used as a development assistant throughout this project. It helped with coding, debugging, database operations, and improving the user interface. I reviewed and tested the suggested changes while adapting the code to my project's requirements and database structure.
